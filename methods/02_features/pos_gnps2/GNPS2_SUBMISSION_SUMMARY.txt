METADATA INTEGRATION STRATEGY
================================================================================
Samples were matched to taxonomic metadata from:
  GNPS_Master_Sample_Mapping_Positive.xlsx (262 entries)

Matching strategies (in order of priority):
  1. Strip ".raw Peak area" suffix from column names (direct match)
  2. Case-insensitive exact match
  3. Strip timestamp suffixes (e.g., _20230211043148)
  4. Extract short code by removing batch prefixes (OE11-3-E4-, OE21-4-, etc.)
  5. Match short codes with metadata having batch prefixes stripped
  6. For OE21-2 samples, match against OE21-4 metadata (same organisms)
  7. Check if sample appears in GNPS Filename column

Sample Classification:
  - BIOLOGICAL: Matched to metadata with Kingdom assigned
  - QC: Sample name contains POOL, QC, SRM, ISTD, COND, ESTD, BLANK, SBLK, EQ
  - UNKNOWN: All other samples (unable to match to metadata)

METADATA TSV FORMAT
================================================================================
Each gnps2_metadata.tsv file contains the following columns:

  filename                    - Original sample column name from CSV
  ATTRIBUTE_Kingdom           - Kingdom (Bacteria, Archaea, Fungi, Animalia, 
                                Plantae, Protozoa, Viruses, Mixed, QC, or empty)
  ATTRIBUTE_Phylum            - Phylum/division level classification
  ATTRIBUTE_Class             - Class level classification
  ATTRIBUTE_Order             - Order level classification
  ATTRIBUTE_Family            - Family level classification
  ATTRIBUTE_Genus             - Genus level classification
  ATTRIBUTE_Species           - Species and strain information
  ATTRIBUTE_SampleType        - Original sample type from master metadata
  ATTRIBUTE_KingdomGroup      - Simplified kingdom group for GNPS2
                                (Bacteria, Archaea, Fungi, Animalia, 
                                 Plantae, Other, QC)

Quality Control markers are labeled with Kingdom="QC" across all taxonomic 
levels to maintain data integrity and distinguish them from biological samples.

   batch-specific identifiers not present in the master metadata file.

5. The "Other" KingdomGroup includes Protozoa, Viruses, and Mixed organisms
   that fall outside the standard 6 GNPS2 kingdom groups.

6. Quality control samples are uniformly labeled as "QC" across all taxonomic
   fields to ensure proper filtering and identification in GNPS2 analysis.

# Step 02 — Feature lists (cross-batch alignment)

Turns raw LC-MS/MS runs into one feature table per ionisation mode
(Supplementary Method 1). Samples were measured in **6 independent batches**;
each batch was first processed on GNPS as an FBMN job, then this step aligns
the six batches into one table so the same molecule gets the same `feature_id`
everywhere.

## What happens inside

| Sub-step | What it does | Output |
|---|---|---|
| 0. MZmine + FBMN (per batch) | Raw mzML → feature detection in **MZmine 4.9** (IIMN workflow), each batch submitted to **GNPS2 FBMN** | 6 task exports; task IDs in `fbmn_batches_POS.csv` |
| 1. Anchor discovery | Finds features present in ≥3 of 6 batches (5 ppm, ±2 min) — over 15,000 anchors | `01_anchor_discovery/` (not archived) |
| 2. RT drift | Measures retention-time drift of each batch vs reference batch OE23-POS | drift tables (not archived) |
| 3. LOESS correction | Fits a smooth curve to remove the drift (RMSE after: 0.35–0.52 min) | `02_loess_correction/` + plots (not archived) |
| 4. Consensus table | Re-matches all features with tight tolerances (5 ppm, ±0.5 min) → **the feature list** | `consensus_aligned_table.csv` ✔ |
| 5. Library integration | Merges GNPS library matches + molecular family info across batches | `all_library_matches_combined.tsv` ✔, `all_cluster_summaries_combined.tsv` ✔ |

**Result:** 273,248 features × 263 samples (positive); 122,571 × 200 (negative).

Reads: ← 6 FBMN batch results from GNPS (quantification, library matches,
cluster summaries per batch) + sample metadata.
Used by: → 03 biomarker atlas and everything after it.

## Files here

| File | What it is |

| `fbmn_batches_POS.csv` | The 6 batches: samples, feature counts, kingdoms, **GNPS2 task IDs** (from Table S2) |

| `all_library_matches_combined.tsv` | GNPS library matches merged across batches (sub-step 5) |
| `columns_POS.txt`, `columns_NEG.txt` | Column lists of the two consensus tables |

# SoilLipidAtlas

Curated repository for **SoilMass Paper 2** — *Distributed lipid fingerprints encode
phylum-level identity across the soil food web* (manuscript under revision).

This repository is built up **one reviewed folder at a time** from the working
package on this computer (`Desktop/P2R`). Nothing lands here before it has been
read and understood; every folder carries its own `README.md` explaining:

- what each file is,
- which script or step produced it,
- which results use it.

## What is deliberately NOT in this repository

- Large raw and external data (~21 GB: instrument files, public-database
  downloads, bulk outputs). These stay on disk / in data archives and are
  tracked here only by checksum lists, so their integrity is still provable.
- Rebuildable software environments (R libraries, Docker images) — recipes to
  rebuild them are included instead.

## Status

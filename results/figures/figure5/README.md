# Figure 5 — ClimGrass composition and treatment responses

Biomass-converted community composition of ClimGrass soils and phylum-level responses to drought and warming.

**a**, Biomass estimates per organism group (fc-weighted, 95% CI) after conversion from lipid signal using total lipid content (Table S6) — grey segments are literature biomass ranges. **b**, Drought vs warming log₂ fold changes for 16 phyla (CLR + permutation tests).

Rendered from `r/fig5_final.R` (183 × 150 mm, `soilmass_style.R` Wong palette). Display labels follow Viridiplantae / Protists; see Methods and Table S6 for conversion factors and sources.
